# Bray-Core 性能三方对比基线（上游 / 优化前 / 优化后）

- 生成：2026-08-06
- 上游基准：Xray-core v26.7.28（`5ca6f4b7`）
- 优化前：bray `cde3f9de`（`bench_results/compare/all/`，count=3）
- 优化后：bray `862089c4`（`bench_results/compare/`，默认套件 repeats 3 × count 3，9 样本中位数）
- 单位：ns/op（越低越好）；Δ 为相对上游的百分比（负 = Bray 快）

> **重要判读**：本轮唯一产品代码优化是 vless `DecodeResponseHeader`（2910e126）。
> 其余场景（xhttp/buf/reality/dns）优化前后**无代码改动**，两侧数值差异属
> 测量波动（优化前单轮 count=3 vs 优化后 9 样本，且跨天运行），只作参考，
> 不作为优化收益。

## 结论

1. **唯一真实优化**：vless DecodeResponseHeader，从落后 7-13% 翻转为领先 10-22%（栈缓冲化，2910e126）。
2. **无代码改动的场景**：方向判定跨运行稳定（packet-up 系 Bray 快 98-99%；短连接三场景上游快 6-21%，波动大；stream 系 tie~快 10%）。
3. **新增测量场景**：ColdStart/TCP_Echo（冷启动分解）、dns（池化差异已标注）——无历史优化前数据。
4. 后续对比一律以套件默认（repeats 3 × count 3 + TCP_Echo 基线）为准，单轮数值不作结论。
